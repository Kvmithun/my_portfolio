About

Engineering profile

"I learn the fundamentals, build something, break it, understand why it broke, then go deeper."

I'm an AI/ML engineer focused on generative AI, RAG, and applied machine learning — I care more about how a system behaves end to end than about any single model in isolation.

When something breaks, I debug it, read the documentation, try a few different approaches, and dig for the root cause instead of patching around the error. That habit is what pushed me from notebooks into full pipelines: ingestion, validation, training, serving, and the CI/CD that keeps it running.

My work connects data, machine learning, deep learning, generative AI, RAG, backend services, databases, MLOps, and deployment into systems that actually run — not just scripts that produce a number once.
